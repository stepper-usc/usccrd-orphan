This is a repository containing 3 versions of the University of Leeds Modern Adaption of the Orphan of Zhao.

The first contains the original text from the following link, labeled in the site as (中文版剧本 (Chinese Script))
https://archive.researchdata.leeds.ac.uk/256/?utm_source=chatgpt.com

The second and third version of are graded version of the text for speakers with 500 characters memorized, and for speakers with 1000 characters memorized.

Each version comes with a word bank. For the 500 character version, this includes words outside of those 500 characters, 1000 characters for the 1000 character version, and 2000 characters for the original version.

Note: These simplifications and word banks were developed using ChatGPT's GPT6, for the purpose of reading within a reading group.
