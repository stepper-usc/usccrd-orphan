# What is this repo?
This is a repository containing 3 versions of the University of Leeds Modern Adaption of the Orphan of Zhao.

The first transfer the original University of Leeds modern adaption of the Orphan of Zhao into a more readable HTML format. The original script can be found here under the label (中文版剧本 (Chinese Script))
https://archive.researchdata.leeds.ac.uk/256/?utm_source=chatgpt.com

The second and third version of are graded version of the text for speakers with HSK 4 (Version 2.0) level vocabulary, and HSK 6 level vocabulary.

Note of Use of AI: The HTML files were generated using GPT6. GPT6 was also used to grade the original text for HSK 4 and 6.
